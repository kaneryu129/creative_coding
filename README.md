## 座標（場所）の考え方
- 画面上の場所は x (横) と y (縦) の 2 つの数字で指定します。

- 左上がスタート地点 (0, 0) です。

- x (横)：右に行くほど数字が大きくなります。

- y (縦)：下に行くほど数字が大きくなります。（数学のグラフと逆なので注意！）



## 📐 基本の図形（カンニングペーパー）よく使う図形の書き方リストです。
```ruby
丸circle(x, y, 直径)
四角rect(x, y, 横幅, 縦幅)
三角triangle(x1, y1, x2, y2, x3, y3) ※3つの点の場所を指定線
line(x1, y1, x2, y2) ※始まりと終わりの場所を指定文字
text("書きたい文字", x, y)
```
## 🎨 色と見た目の変え方
図形を描く直前に、設定を変更する命令を書きます。

```
1. 中身を塗る：fill(赤, 緑, 青)
数字は 0 から 255 の間を選びます。

fill(255, 0, 0) → 赤色

fill(0, 0, 255) → 青色

fill(255, 255, 0) → 黄色

fill(0) → 黒色

fill(255) → 白色

2. 枠線を決める
stroke(赤, 緑, 青)：線の色を変える

strokeWeight(数字)：線の太さを変える

noStroke()：枠線を消してスッキリさせる
```
